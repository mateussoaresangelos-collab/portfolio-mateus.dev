Portfólio Pessoal

Site profissional com apresentação de projetos, responsive e com foco em UX.

Visão Geral

Este projeto apresenta o meu portfólio pessoal com foco em apresentar trabalhos, habilidades e contato para recrutadores e clientes.

Tecnologias

HTML CSS JavaScript

Objetivo

Construir um site limpo, rápido e responsivo para apresentar meu trabalho e facilitar o contato profissional.

Problemas resolvidos

  • Organização de conteúdo para apresentar projetos com clareza.
  • Implementação de tema escuro/claro persistente.
  • Layouts adaptáveis para diferentes tamanhos de tela.

Aprendizados

  • Melhoria nas práticas de estrutura semântica de HTML.
  • Otimização de imagens e performance básica.
  • Padronização de componentes reutilizáveis em CSS.
